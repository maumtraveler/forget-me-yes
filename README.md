# 건망증과 동거중

외출·여행·등산 등에 필요한 준비물과 물건의 위치를 기록하는 웹앱입니다.

## 사용 방법

1. `index.html`을 웹 브라우저로 엽니다.
2. 준비물이나 물건 위치를 입력하고, 화면의 버튼으로 수정·삭제·체크합니다.
3. 입력한 내용은 서버가 아니라 현재 브라우저의 `localStorage`에 저장됩니다.

## GitHub Pages에서 사용하기

이 폴더의 파일을 GitHub 저장소에 올린 뒤 GitHub Pages를 켜면 됩니다. 시작 파일은 폴더 맨 위의 `index.html`입니다.

브라우저 저장소에만 데이터가 저장되므로, 브라우저 데이터나 기기를 바꾸면 기록이 사라질 수 있습니다. 공개 저장소에는 개인정보를 입력하거나 올리지 마세요.
